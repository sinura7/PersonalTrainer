# P16 plan preview and acceptance

Labeled before the behavior is treated as done. The phone check stays later.

## Preview

The last step shows the week that would be created: the days, the routines, and the lifts. Changing the days or the equipment and coming back shows that new week. The other answers stay as they were. Nothing is written while the person is only looking.

## Accept once

Use this plan writes the program one time for this visit. A second tap, or opening setup again after the process is recreated without a new visit, does not add another set of routines or another set of days. A cardio week has no routines; that visit is still remembered, so a second tap does not start a second twelve-week block or log the weigh-in again.

A later visit, such as Settings → Add a new block, is a new visit and may add a week alongside what is already there.

## What an existing program is told

If routines are already on the phone, the preview says so before Use this plan: the new routines are added alongside, history stays, and accepting starts a new twelve-week block.

## Generate a week

Settings → Generate a week is a different door. It still asks first, then adds a fresh set of routines inside the current block. It is not a second tap of the setup visit.

## Leaving

Back from the first question, or I'll build my own, writes no program. A failed attempt does not leave the new routines behind, and the same visit can be accepted once after that failure.
