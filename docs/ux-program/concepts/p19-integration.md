# P19 field purpose

Labeled with the fix. A physical screen reader stays with the phone check.

## What a field says

Search says "Search exercises" when it is empty and after a lift is typed. The routine title says "Routine name" when it is empty and after a name is typed. The placeholder is only the grey hint. It is not the name a screen reader is left with once the field has text.

## What this packet does not close

Walking the whole app with TalkBack, large text on every screen, and reduced-motion timing on a phone are still the owner's check. This packet does not claim those.
