# P15 onboarding concept

Labeled before the code. The phone check stays later.

## Question

Each step has one visible question. The header says which number it is. A single choice moves on when it is tapped. A step with more than one answer has Continue.

## Skip

Bodyweight can be left empty. The button says Skip this until a weight is chosen, and Skip this stays available after a weight is chosen. Skipping stores no weight. Which days can be left empty; the button then says Space them out for me.

## Back

Back returns to the previous question. The answer that was chosen is still selected. The first question's Back leaves setup and does not write a plan.

## Units

The bodyweight wheel can show kilograms or pounds. The number stored is kilograms. Changing the unit changes the label, not a weight that was already stored.

## Focus

When the question changes, the question title is the place a screen reader lands.

## Small window

At 360 by 640 dp and large text, Continue and Skip are still on the scrolling page. They are not clipped off the bottom with no way to reach them.
