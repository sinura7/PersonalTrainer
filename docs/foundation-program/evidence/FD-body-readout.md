# Body readout — evidence

Packet: Body is an information page. Day / week / month chips wash the
silhouette from logged work. Empty still shows the figure. There is no
Start Volt on this tab.

## What changed

- `HeatWindow` is Day / This week / This month. A stored `LAST_30_DAYS`
  becomes this month.
- Heat lights from the first credited set. Junction weight still splits
  the lift; reps and RPE scale how hard that set was. Unlogged RPE is a
  completed set (1.0).
- Empty Body keeps the figure and the muscle list. Copy is
  `Finished sets light the figure.` Start lives on Home. Find lifts
  stays on the muscle sheet. Fault still offers Retry.
- Recommendations that would Start a workout are not shown here.

## Commands

- `tools/preflight.sh`
- `./gradlew testDebugUnitTest`
- `./gradlew assembleDebug`

## Known limitations

- Year / all-time are History chips, not a second silhouette.
- Phone judges Temper Debug via Obtainium.
