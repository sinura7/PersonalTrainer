## Behavior contracts

**Google Sign-In types are gone.** `DriveAuthClient` no longer imports
`com.google.android.gms.auth.api.signin`, `GoogleSignIn`,
`toGoogleSignInAccount`, or `getSignInClient`.

**AuthorizationClient + drive.file stay.** play-services-auth is
21.6.0. Scope is still `https://www.googleapis.com/auth/drive.file`.
Credential Manager and extra identity scopes were not added.

**Email is a Drive About read.** `DriveAboutJson.parseAccountEmail`
reads `user.emailAddress`. If About fails, Settings still shows
signed-in as "Google Drive" so a successful token is not lost.

**Sign-out revokes.** `AuthorizationClient.clearToken` then
`revokeAccess`. Local Drive prefs are cleared either way.

**Local recording stays Google-free.** Workout, history, and file
backup do not import Play Services.
