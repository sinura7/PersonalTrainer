## Behavior contracts

**Channel off.** Shipping `android:allowBackup="false"`. The debug
package has `FLAG_ALLOW_BACKUP` unset.

**Named excludes.** `backup_rules.xml` (legacy) and
`data_extraction_rules.xml` (API 31+ cloud-backup and device-transfer)
exclude `root`, `file`, `database`, `sharedpref`, and `external`, and
name Room, DataStore, rest-timer prefs, schema marker, safety
snapshots, the restore journal, and the pre-migration copy.

**Upgrade-in-place.** File-backed Room close/reopen keeps the finished
session. Private files and SharedPreferences on the same process files
survive. Auto Backup will not replace them.

**Already-taken OS copies are not recalled.** They are luck, not a
plan, and not a supported channel.

## Production change

Manifest points at both rule files. `tools/check-backup-policy.py`
ratchets the flag and the named stores. README and RECOVERY say the
channel is disabled. Threat-model T3 is closed.
