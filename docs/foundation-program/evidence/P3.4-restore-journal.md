## Behavior contracts

**One lock.** Start, repeat, and `commitRestore` take the maintenance
mutex. A start begun while the lock is held waits. A start begun while
a restore journal is open is refused.

**Journaled phases.** staged → wiping → room → prefs → clear. Room
replacement stays one transaction. Preferences and catalog reconcile
can finish after process death. *(Historical, as of `219b069`. The
current machine adds a terminal `done` phase before cleanup, decides
`wiping` by a content witness, and keeps the journal open for a
preferences retry — see [HANDOFF-2026-09-06.md §2](../../HANDOFF-2026-09-06.md).)*

**Named failure.** If Room has already committed, the error says the
training data was replaced and settings will finish on the next launch.
A staged-only crash clears the journal and leaves the phone unchanged.

**Startup recover.** `PersonalTrainerApp` finishes an open journal
before catalog seed.
