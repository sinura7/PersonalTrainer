## Dedicated contracts added

Assertions read Room, DataStore, and public state/effects.

**Onboarding Gate (4):** unread stays UNKNOWN; first install → SETUP;
finished → APP; completing setup flips the live gate.

**Routine Editor (12):** new vs existing vs missing; add creates the stub;
duplicate add; leave discards an emptied stub; leave persists name/notes;
stage/commit targets and zero-set rejection; remove/move; swap keeps
position; create-and-select blank/duplicate; pending-add confirm.

**Custom Week (7):** empty week cannot confirm; add → confirm writes the
named day and completes onboarding; duplicate lift ignored; draft
move/remove/targets do not write until confirm; guided seed picks the
first preferred day and holds the weight unit; shared duplicate-name
copy; picker dismiss clears search/pending.

**Exercise Library (12):** grouped catalog; query and muscle filter;
one-shot route seed; create/blank name; built-in edit/delete refused;
unused custom delete; used custom blocked; add-to-routine already/
missing/success; collision keep-both; family expand.

**Exercise Detail (6):** blank and missing ids; membership flags;
finished history; already-in notice; add persists without inventing a
target weight.
