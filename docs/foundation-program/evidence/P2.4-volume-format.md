## Behavior contracts

**100 lb × 5:** stored kilograms of a 100 lb loaded set, times five,
format as `500 lbs`. The old Summary `roundToInt` path would print 501.

**Ties-to-even:** 0.5 → 0, 1.5 → 2, 2.5 → 2, 3.5 → 4.

**Surfaces:** `formatVolumeLabel`, `formatVolumeNumber`,
`volumeAnimationTarget`, and `SetCopy.workColumn` emit the same digits
for both units across grouping, `.5` boundaries, and large values.

## Production change

`WeightConverter.volumeDisplayWhole` is the only aggregate rounding.
Summary animates to `volumeAnimationTarget` and announces
`formatVolumeLabel`. History / Session Detail / Exercise Detail
already shared `SetCopy`; the column now calls `formatVolumeNumber`.
