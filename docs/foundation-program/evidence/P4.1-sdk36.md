## Behavior contracts

**SDK triple.** `compileSdk = 36`, `targetSdk = 36`, `minSdk = 26`.
The installed debug package reports `ApplicationInfo.targetSdkVersion == 36`
on the API 29 device.

**Official pair.** AGP 8.9.2 and Gradle 8.11.1. API 36 requires AGP
≥ 8.9.1. Compose, Room, Lifecycle, and KSP/Kotlin stay for P4.2–P4.4.

**Predictive back.** Manifest sets `enableOnBackInvokedCallback=true`
with `tools:targetApi="33"`. Screens that intercept back already use
`BackHandler`.

**Robolectric lane.** 4.14.1 does not ship an API 36 jar.
`robolectric.properties` pins `sdk=35`. DefaultSdkPicker no longer
requests 36 from compileSdk.

**Lint.** New AGP 8.9 detectors that would jump to AGP 9 or inflate
Robolectric-blind timer bytecode (`AndroidGradlePluginVersion`,
`UseKtx`) are disabled. Durable `commit()` stays. Existing baseline
findings remain; a new warning is still an error. P4.6 owns
zero-warning cleanup.
