## Behavior contracts

**Platform crypto only.** PBKDF2-HMAC-SHA256 (210,000 iterations) and
AES-256-GCM. Salt and nonce are random per wrap. The key is derived
from the typed password, never from Android Keystore.

**Default export is protected.** File and Drive export ask for a
password, wrap the existing BackupJson document, and do not store that
password. Cancelled pickers wipe the held secret.

**Legacy plaintext still imports.** `BackupEnvelope.open` returns a
non-envelope file unchanged. An envelope without a password asks; it
does not decode as an empty catalog (no `version` field on the
wrapper).

**Plaintext is advanced.** Export without a password is a warned
choice. Status copy does not call the file private.

**Wrong password and tamper fail the same way.** GCM tag failure and a
bad guess both say the password does not open the file.
