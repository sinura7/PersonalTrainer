## Behavior contracts

Assertions count compute invocations, compare shared instances, and
read public `TrainingInsights`. They do not inspect private jobs.

**Shared collectors (2):** two `observeShared(true)` collectors run one
compute and receive the same instance; two cold `observe()` collectors
do not share.

**With/without week (1):** two with-plan collectors share; the
without-plan collector is a second pipeline and has a null `weekPlan`.

**Replay / grace (2):** a resubscribe inside the grace window replays
without a recompute; a standing collector after grace sees a second
compute.

**Refresh (1):** a new refresh value recomputes against unchanged
history.

**Latest-input / cancellation (2):** a hanging first hint load never
emits; a later Room write cancels it; the collected result is the
latest history and never a `PROGRESSION` fallback.

**Failure isolation (1):** a thrown hint load marks `PROGRESSION` and
still produces a heat snapshot.

**Off main (1):** compute runs on the injected `insights-compute`
thread, not the collector thread.

## Production seams

`compute`, `loadHints`, and `shareGraceMs` default to the production
calculator, `WorkoutRepository.readyForProgression`, and a 5 s
`WhileSubscribed` grace. Tests inject them. The default path used by
`AppContainer` is unchanged.
