## Behavior contracts

**Prepare does not write.** `prepareRestore` decodes, validates, and
compares authored inventories. `commitRestore` is the only writer.

**Authored ≠ catalog.** Built-in exercises do not count. Sessions, sets,
routines, custom exercises, schedule slots, weigh-ins, and blocks do.

**Catalog-only refuse.** A file with only seeded lifts cannot replace a
phone that has authored data, including DataStore-only bodyweight or
blocks.

**Confirm copy** names both sides and does not say a safety copy is
already saved (that promise is P3.3).

## Production change

`AuthoredInventory` plus `prepareRestore` / `commitRestore`. Settings
reads the file or Drive backup first, then shows the comparison, then
commits.
