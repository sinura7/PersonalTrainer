## Behavior contracts

**Claim ledger (7):** current+due claims once; stale id ignored even
when due; blank incoming is stale; early matching id is not claimed
and can still claim when due; replace leaves the previous id unable
to claim; skip/cleared expected id is stale; 16 concurrent claimers
produce one winner.

**Store (3 added):** start and adjust mint distinct ids; restore keeps
the given id; persistence writes the id.

**Rehydrate:** same-boot running and expired carry the id. A different
boot returns `None` (short rest is cleared, not rebased or announced).

## Production change

`RestTimerSnapshot`, `PersistedRestTimer`, alarm extras, the service
tick, and `RestTimerCompletion.completeOnce` all key on `timerId`.
Claim requires matching id **and** `nowElapsedRealtime >= deadline`.
Early matching delivery reschedules the current alarm. Stale delivery
cannot stop a replacement rest.
