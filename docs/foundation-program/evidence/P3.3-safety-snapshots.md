## Behavior contracts

**Verified before teardown.** `commitRestore` encodes the current phone,
writes a safety copy, fsyncs, re-reads it, and refuses unless authored
counts match. Room is not touched until that copy verifies.

**Failure aborts.** A missing or unwritable snapshot directory throws
and leaves existing sessions in place.

**User-recoverable.** Settings lists retained copies as "Safety copy"
with counts and a date. Export, restore-through-preview, and delete
are offered. Raw private paths are not shown.

**Confirm copy** now honestly says a verified copy is saved first.
