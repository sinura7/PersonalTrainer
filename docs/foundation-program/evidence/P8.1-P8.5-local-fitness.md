## Behavior contracts

**P8.1 / FND-010 / FND-039.** `TemperDatabase` migrates v3 → v4.
`measurable_goals` is empty after migrate. `bodyweight_entries` gains
`zoneId` and `offsetSeconds` (default UTC / 0). Goal periods and
bodyweight writes persist the ADR-011 four-tuple. Home, Plan, and the
History list/calendar read `SessionSummary` aggregates, not every set.
Past-block reviews and the PR strip use windowed graphs or
`sessionsBetween`. `fallbackToDestructiveMigration` is absent.
Generated `4.json` is committed (`identityHash`
`36020a1688866d410003a11bdee60227`). `FoundationGeneration.VERSION`
is 4. `FROZEN` stays true. Export version is 5; v4 files still decode
with an empty `measurableGoals` array.

**P8.2 / FND-009 goals.** Typed goals: adherence, session count,
active minutes, lift target, cardio duration/distance, optional
bodyweight. Adherence is trained days over expected training days,
not a consecutive-day streak. Pause is first-class and never counts
as met. Goals are a pushed route from Home and Plan. Four tabs remain
Home · Body · Plan · History. Home shows at most one compact snapshot.

**P8.3 / FND-009 horizons.** History chips are Today / This week / This
month / This year / All time. Body heat is Day / This week / This
month. Year and all-time are not `HeatWindow` values.

**P8.4 / ADR-008.** Every recommendation and progression hint from
`TrainingInsightsCalculator` carries a local `RuleTrace`. The card
renders Why from that object. No remote explanation API.

**P8.5 / FND-010 / FND-038.** The 500-session / 15,000-set fixture
still encodes and snapshots under the signed ceilings (2 s encode,
2 s decode, 4 s snapshot+encode, 8 MiB UTF-8). Measured on this host:
encode 106 ms / 4,189,344 bytes; decode 175 ms; snapshot+encode
194 ms / 4,189,364 bytes. Five hundred summaries project in well
under a second. Whole-document encode stays. No streaming rewrite.

## Limitations

performed instant and the current default zone. Activity, goal, and
bodyweight rows use the captured local date. Legacy `schedule_slots`
and `WeekDerivation` remain for pin editing. This debug install
(`com.sinura.personaltrainer.debug`) is a separate id from a release
phone. Phase 9 is not opened.
