# Guided setup — generated programs

Every program `RoutineGenerator` can produce, rendered from the shipped catalog. Do not edit this file by hand — it is golden-file tested against the renderer, so a hand edit fails the build. Re-render with `tools/render-artifacts.sh`.

**How to read it.** Each block is one set of answers. The split is *derived*, never asked.
Sets, reps and rest come from `AddDefaults`, the same rule a hand-added lift uses.
Lift order is compounds first — the lift that asks most of you should meet you fresh.

**To change a judgment call** — which families make a session, or their order — edit
`RoutineGenerator.TEMPLATES`, re-render, and review the diff here.
