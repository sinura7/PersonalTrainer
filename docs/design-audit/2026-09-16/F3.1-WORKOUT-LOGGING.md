## Changed contracts

- The screen order is the owner's reference: session header with `n of N
  exercises · x of y sets` and one progress segment per lift (landscape: one row,
  the plan's words as the title); 88 dp image-led
  exercise identity with equipment kicker, name, `Set n of T`, working count,
  Details and Working | Warm-up; Last set · Best set · Volume for this lift;
  weight and reps (or hold time) as two hero numerals with round − / + plates
  and tap-to-type; RPE 6–10 between Easy and Max effort with help and Clear;
  Next set with the change, the rule, Why and Apply; today's sets as chips with
  the current set ringed, Edit and Add set; the dock with the rest card (or the
  hold / set clock bar) and a 72 dp two-line Log set naming its payload, or
  Next exercise naming the next lift on its capped supporting line (spoken only
  in landscape, which has no room for a second line).
- Every number is derived from saved rows. `WorkoutProgressCalculator` owns the
  header numbers and segments; `ExerciseFloorStatsCalculator` owns Last set
  (today, else last time, else First set), Best set (the standing-records rule
  over other sessions plus today's working sets) and Volume (`WorkoutSession.work`).
- The ViewModel contract is unchanged except one read-only flow,
  `exerciseHistory`, loaded with the prefill. Logging, editing, undo, the derived
  primary action, `WorkoutAdvance`, the rest gateway, `Coach.decide` and
  `IncrementTable` are called, not copied.
- Apply copies the next set into the entry and never logs; once the entry
  matches it reads Applied. A suggestion is never rendered as a selection.
- The rest card is the service's clock: running (cyan ring, −15 / +15 / Skip),
  done (gold `Back to the bar` flash), at rest (planned length, Start rest).
  Duration editing stays in the sheet. Holds and the set stopwatch keep the
  56 dp instrument bar. Nothing on the floor counts on its own.
- Log set stays the one filled Volt. Selected states are a Volt outline on a
  dim Volt tint. Coral stays on the muscle stills; cyan stays on timing.
- Plates never move: whether − / + sit beside or beneath a hero numeral is
  decided from a fixed widest sample, and font 1.6 and above stacks the two
  columns (`LogLoopScale.stackEntryWells`). The unit rides the weight numeral's
  baseline; the kicker names only the field.
- Last time stays reachable without the old chip strip: the Last set cell applies
  last time's final set until today's first set lands, and `Plan` / `Last`
  one-tap fills appear under the weight numeral only while the entry holds
  something else (ADR-027 decision 9).
- Applied is the domain's word (`SetMicroRec.isApplied`): the same coercions
  Apply writes, weight at display precision, effort matched exactly.
- No automatic advancement: after the last planned set the primary becomes
  Next exercise (or Finish workout) and waits for a tap; Add set stays explicit.
