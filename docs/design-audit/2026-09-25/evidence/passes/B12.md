### Notes on §2

**AX-1.** Counter-evidence looked for: a single merged node — there is none, because the two `clickable`s sit on sibling layouts (`:467-473` and `:531-540`) under a non-clickable Column (`:450-455`); a role — `Role.Button` is used by `InstrumentRow` (`:383`) but `SessionLogRow` never went through it; a height floor — the outer Column's `heightIn(min = Metrics.rowMin)` (`:453`) covers the whole row, not the identity target. Fix shape: one `clickable(role = Role.Button)` on the Column at `:450` with `clearAndSetSemantics { contentDescription = spoken }`, the menu kept outside it as now; then `:531-534` loses its click. Home's recent list does not use this row (callers are History only).

**AX-15.** Counter-evidence looked for: a typed path anywhere in `ui/reminders` (grep `NumberEntryDialog|typing|customActions|stateDescription`: none); semantics inside `SnapWheelColumn` (none: `:52-89` is layout and `Text` only); a `selectableGroup`/`Role` on the pager (none). TalkBack can scroll a `VerticalPager` with two-finger swipes and the `settledPage` collector (`ReminderTimeWheel.kt:47-64`) would commit, so "cannot set" is R; "cannot tell which column is which, what it holds, or type it" is C. `TalkBackPolicyTest.kt:66-68` pins the bodyweight wheel's typed path, not this one.

**AX-14.** Counter-evidence: `StatTile` (`GymSurfaces.kt:294-311`) uses the same merge-plus-description shape but builds `spoken` from label, value, unit and caption, so it is not affected; the History card copied the shape and not the sentence. No test under `app/src/test` references `HistoryTags.READOUT` at all.

**AX-2.** Counter-evidence: `WeekStrip.kt` (Plan/Home) does this right — `selectable(role = Role.Tab)` in a `selectableGroup` with `WeekBoard.spoken` naming fill and selection (`:118-126`, `domain/WeekBoard.kt:88-111`). The custom-week strip is a second, older copy. Fix shape: reuse `WeekStrip`'s pattern (`selectable(selected, role = Role.Tab)` + a spoken form from `CustomWeekPolicy.dayMark`), and the F4 scroll-when-narrow rule.
